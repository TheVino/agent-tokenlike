# New Rooms Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the Secret Room, Cracked Idol and Traveler's Campfire rooms, a typed pending choice, temporary effects and a Journal window.

**Architecture:** Rules stay pure in `dungeon.py`. `run["pending"]` gets a `kind` and `choose_pending`/`auto_choice` dispatch on it. `run["temp"]` holds timed `fx` summed in `stats()`. The GUI in `tokenlike.py` only draws: one choice window for every kind, one animation branch per room and a `show_journal` window.

**Tech Stack:** Python 3 standard library, tkinter. Pillow is allowed only in `tools/`.

**Spec:** `docs/superpowers/specs/2026-11-16-new-rooms-design.md`

## Global Constraints

- Standard library only in the app.
- Code, comments, identifiers and commits are in English. Every visible text goes through `t()`/`_t()` and has a `PT` entry in `i18n.py`.
- All art is original, as text grids in `art.py`. No names or art from existing games.
- Every new box uses `pixel_box`/`card_box`/`chip`/`rounded_rect`/`shorten`/`tooltip`/`scrollbar` and passes `tests/test_texts.py` in pt and en.
- Balance targets stay as they are: 35–45% pass the 1st boss, p90 13–16, max ≤ 50 (`tools/balance_stats.py` `TARGETS`).
- `RULES_REV` goes from 9 to 10, once, in Task 1.
- Inactivity never punishes. The idol never kills: at least 1 HP is left.
- Never enter a room while a choice is open (today's rule).
- Run the whole test list from `CLAUDE.md` after each task. `test_gui.py` takes 10–25 min, so run it in the background.

## Review Focus

1. An old save whose pending has no `kind` but a valid `key` must load as an `offer` and keep working. Test it in Task 1.
2. A save with an `idol`/`campfire` pending must survive `migrate_run`. If its `line` or a boon is unknown, it is dropped. Test it in Task 1 and Task 4.
3. `roll_offer` reads `run["pending"]["key"]`. With an idol or campfire pending it must not crash. Test it in Task 1.
4. The GUI footer (`tokenlike.py:2599`) and `play_room` (`:2076`) read `pending["key"]`. A non-offer pending must not crash them. Test it in Task 6.
5. Idol accept at 4 HP leaves 3 HP. At 1–3 HP only "decline" exists, and a forced "accept" from a stale window is treated as "decline". Test it in Task 3.

### Task 4: Traveler's Campfire, tales and boons

**Files:**
- Modify: `dungeon.py` (`TALES`, `BOONS`, `enter_room`, `CHOICES`, `ROOM_WEIGHTS`, `new_meta`), `art.py` (room art `campfire`, `TALE_ART` for `ghost`/`wanderer`/`traveler`), `i18n.py`
- Test: `tests/test_items.py`, `tests/test_i18n.py`

**Interfaces:**
- Consumes: `CHOICES`, `add_temp`.
- Produces:
  - `TALES: dict[str, {"who": "ghost"|"wanderer"|"traveler", "text": str}]`, 16 entries. The text is English, at most 90 characters, original, dark and cute. Every text gets a PT entry.
  - `BOONS: dict[str, dict]`, with these keys and effects:
    - `rest`: heal 30% of max HP, rounded up;
    - `stone`: +1 base DEF for the run;
    - `coins`: `8 + 3 * floor` gold;
    - `ember`: `add_temp({"atk": 1}, 5)`;
    - `ward`: `3 + floor` shield.
  - `BOON_PRIORITY = ["ember", "stone", "ward", "coins", "rest"]`.
  - Pending `{"kind": "campfire", "line": key, "boons": [3 distinct keys]}`. `valid` checks that the line is in `TALES` and every boon is in `BOONS`.
  - `meta["journal"]: {key: {"run": id, "floor": n}}`, written when the room is entered (heard = seen). Unheard tales are picked first; once all are heard, the pick is random.
  - `boon_text(key, run) -> str`: the English effect text used by the GUI, e.g. "Heal {n} HP".
- [ ] **Step 1: Write the failing tests:**
  - `test_tales_shape`: 16 tales, each `who` in the 3 kinds, `len(text) <= 90`.
  - `test_campfire_prefers_unheard`: 16 campfires in a row hear 16 distinct tales.
  - `test_campfire_auto`: the auto rule picks `rest` when `hp < 0.5 * maxhp` (if offered), otherwise the first offered key in `BOON_PRIORITY`.
  - `test_campfire_rest_not_full_heal`: `rest` never heals more than `ceil(0.3 * maxhp)`.
  - `test_campfire_bad_save`: a pending with an unknown `line` is dropped by `migrate_run`.
  - In `test_i18n.py`: every `TALES` text and every `boon_text` template has a PT entry.
- [ ] **Step 2: Run** the two test files. Expected: FAIL.
- [ ] **Step 3: Implement.**
  - Weight `("campfire", 4)` from `monster`, from floor 2.
  - When `rest` is offered, it is always among the 3 boons, so auto mode can heal. The other 2 are a random sample of the rest.
  - Write the 16 tales. The owner reviews them before merge.
  - Use `meta.setdefault("journal", {})`.
- [ ] **Step 4: Run** all the tests and `python tools/simulate.py`.
- [ ] **Step 5: Commit** `feat: traveler's campfire, tales and boons`.
